Font UI is a small typography workbench on avrxt’s personal website. Use it to compare the shape, rhythm, and readability of text before choosing a typeface for a project.

<Card title="Open Font UI" href="https://www.avrxt.dev/tools/fontui">Try your own sample in the live tool.</Card>

## Try a typeface

Browse or filter the font list, enter representative sample text, and select a family. Compare both short headings and longer sentences. Include numbers and punctuation if those are important to your design, then use the available copy controls.

## Catalog and loading

The catalog uses Google Fonts metadata, with a fallback list when the full catalog is unavailable. Selecting a font loads its Google Fonts stylesheet. The fallback list may not include every available family. A delayed network request can briefly show a fallback typeface before the selected font arrives.

## Copying and reuse

Copying styled text depends on browser clipboard support and the destination application. It does not install a font or guarantee that another app preserves formatting. Where offered, copy CSS and explicitly apply the family in your project. Review the individual font license before distributing the font with a project.

## Privacy and troubleshooting

Sample text is handled by the browser interface. Loading fonts makes requests to Google font services. Use non-sensitive sample text when experimenting. If a preview does not update, allow the font request to complete and check whether an extension blocks it. Compare in your target browser before making a final design decision: operating systems can render the same typeface differently.
