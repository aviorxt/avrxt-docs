Search improvements should help readers understand the website and find useful content. They are not a promise of ranking for broad terms.

## Personal-site identity

Use consistent AVRXT/aviorxt names, accurate visible identity text, canonical URLs, a sitemap of current pages, and truthful structured data. Private dashboards and recipient-specific pages do not belong in public search.

## Separate docs search

Mintlify owns documentation navigation, search, metadata, and its sitemap. Main-site Algolia reconciliation now uses the public page catalog, links to the official docs root, and removes stale CMS article hits. Preview deployments must not rewrite production indexing.

## Page writing standard

Use a unique title and description. Answer a distinct reader question, explain practical steps and limitations, and link to relevant pages. Examples should match maintained code. Do not add doorway pages, repetitive keywords, fake benchmarks, or unsupported compliance claims.

## Old links

The old docs root redirects to the custom domain. The two original articles have explicit new destinations. The removed docs-admin path returns to the main dashboard rather than becoming a public docs page.

## Verification after publishing

Check the live canonical, sitemap, redirects, images, and Google Search Console coverage. A sitemap submission or indexing request does not guarantee inclusion or a top result.
