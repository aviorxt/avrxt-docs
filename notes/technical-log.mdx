## 6 November 2026 — Documentation published

**Status: documentation live at https://docs.avrxt.dev.**

The documentation repository is connected to Mintlify on its main branch. The custom hostname serves the reading pages over HTTPS. The first repository verification workflow passed. The previous Mintlify-hosted drafts were exported before the owner approved replacement with the repository.

Live checks covered the notebook, a tool guide, an API page, the sitemap, and the two archived-article redirects. Starter ZIP downloads are hosted by the main website rather than relying on Mintlify asset delivery. Main-site redirects are a separate release and must be checked after its deployment completes.

The entries below record the earlier preparation stage rather than the current publication status.

## 6 November 2026 — Documentation migration prepared

**Status: local preview; publication pending owner approval.**

The documentation is being moved from the main website into a separate Mintlify project intended for `docs.avrxt.dev`. The main-site changes prepare removal of the embedded editor and documentation administration links, with redirects for the old public article URLs. Publishing those redirects depends on the new documentation hostname being ready.

Two published articles were preserved from the old editor. The draft view contained no unpublished articles at the time of the check. The original source records are retained with the migration files; no production database rows or media were deleted for this preparation.

## 6 November 2026 — Tool reference expanded

**Status: local preview.**

All eight tools have dedicated guides covering use, result interpretation, limitations, and troubleshooting. The Spotify tool is documented as an official preview embed, not an audio downloader. Network checks explicitly explain their observation point and what a successful result cannot prove.

## 6 November 2026 — Practical technical notebook added

**Status: editorial content in local preview.**

New guides cover static hosting, evaluating free service tiers, Cloudflare domain email routing, and Gmail SMTP. Official sources were reviewed for current provider behavior. The Gmail guide includes Google’s announced January 2027 third-party Send as change instead of presenting an older alias workaround as a permanent solution.

## Reading future entries

Private incident details, credentials, recipient data, and administrative session URLs do not belong in this public log.
