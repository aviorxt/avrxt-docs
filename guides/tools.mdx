Visit the [toolbox](https://www.avrxt.dev/tools) for the current collection of utilities.

## Using a tool

Choose a tool, enter only the information needed for that task, and read its result and any source information shown with it. Some tools run in the browser; others call the shared API or an upstream service.

## Network results

Network information reflects what the service can observe at request time. VPNs, proxies, cached responses, unavailable upstream services, and rate limits can affect results.

<Warning>Use network utilities only for systems you own or are authorized to test.</Warning>
