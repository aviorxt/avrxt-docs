AVRXT is the personal website of **avrxt**, also known as **aviorxt**. Each space has a specific purpose.

| Space | Purpose |
| --- | --- |
| [www.avrxt.dev](https://www.avrxt.dev) | Personal website, contact, utilities, and updates |
| [me.avrxt.dev](https://me.avrxt.dev) | Public profile, links, and presence |
| [muzix.avrxt.dev](https://muzix.avrxt.dev) | Listening activity and music snapshots |
| [docs.avrxt.dev](https://docs.avrxt.dev) | Guides, API reference, and field notes |
| [api.avrxt.dev](https://api.avrxt.dev/v1/health) | Shared HTTP API gateway |

## Where to start

<Steps>
  <Step title="Explore a feature">Read the profile, tools, Muzix, guestbook, or newsletter guide.</Step>
  <Step title="Integrate a public endpoint">Start with the API overview and a read-only health request.</Step>
